# 便签本 · note-book

小手机里的一个应用：写一句话，它会被记住。

这是手机自带的示例应用，用来证明「导入 → 桌面出现图标 → 打开 → 存盘 → 卸载」整条路是通的。
想自己写应用，照这个抄最短。

## 怎么装

两种都行：

- 把 `note-book.dshapp` 直接拖到手机上；
- 点手机顶栏的 **＋**，选 `note-book.dshapp`。

装完桌面上立刻多一个图标，不用刷新页面，不用重启。

## 权限

只要一项：`storage` —— 读写这个应用自己的私有设置。它拿不到别的应用的设置，也碰不到文件系统。

## 怎么重新打包

改完这个文件夹里的东西，在仓库根目录跑：

```sh
node dev/pack-apk.mjs note-book
```

会把 `apk/note-book/` 重新打成 `apk/note-book.dshapp`。
