# 音乐 · music

小手机里的一个应用：搜歌、播放、滚动歌词，还能自己建歌单。

## 先说明一件事

这个应用只负责画面和交互。搜歌、取歌词、存歌单这些活在 DSH 的 `dsh-music` 插件里，
应用通过手机转发过去。**所以光装这个包放不出歌，还得装上 `dsh-music` 插件。**

## 怎么装

两种都行：

- 把 `music.dshapp` 直接拖到手机上；
- 点手机顶栏的 **＋**，选 `music.dshapp`。

## 权限

| 权限 | 意思 |
|---|---|
| `host` | 可以让手机替它去问后端。手机只转发到清单里写明的那个后端（`dsh-music`），不会送到别处。 |
| `storage` | 读写自己的私有设置：音量、搜索历史。 |

## 怎么重新打包

`main.js` **不是手写的**，是从 `dsh-music` 的网页半生成出来的。要改界面，改源头的网页半，
不要直接改这里——直接改，下次重新生成就被覆盖了。

生成 + 打包两步：

```sh
node dev/build-music-app.mjs   # 重新生成 main.js（在 dsh-phone 的工作目录跑，需要隔壁有 dsh-music）
node dev/pack-apk.mjs music    # 打成 apk/music.dshapp
```

只改了清单、图标、许可证这类不经过生成脚本的东西，跑第二条就够。
